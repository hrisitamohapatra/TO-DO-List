# TO-DO List

This **To-Do List Web App** is a lightweight task manager that allows users to add, manage, and organize tasks easily. Built with **HTML, CSS, and JavaScript**.

---

## Features

-  Add new tasks with ease
-  Mark tasks as completed
-  Filter by **All**, **Pending**, or **Completed**
-  Delete individual tasks
-  Clear all tasks at once
-  Theme-friendly design (integrates well with custom themes)

---

## Built With

- **HTML5** – Markup and layout
- **CSS3** – Styling and layout
- **JavaScript** – Task logic and interactivity

---

## File Structure

- index.html: Main HTML for the to-do interface 
- style.css: Styles for layout and task display
- script.js: All task management logic

---

## How It Works

- Tasks are stored in a JavaScript array (in-memory)
- Users can:
  - Add tasks with the input field
  - Mark them complete using checkboxes
  - Filter based on task status
  - Clear all tasks in one click
- CSS classes help visually separate task states (e.g., completed)

---

##  Example Usage

1. Type a task in the input field.
2. Click **"Add"** to add it to the list.
3. Click the checkbox to mark it complete.
4. Use the tabs (**All / Pending / Completed**) to filter tasks.
5. Click **X** to delete specific tasks or **Clear All** to reset.

Note: Tasks are not saved permanently—refreshing the page will clear the list unless persistent storage is added.
